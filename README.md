🔥 GasSafe – Segurança e Tecnologia

📌 Sobre o projeto

A GasSafe é um projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas, com o objetivo de promover mais segurança por meio da tecnologia e da detecção de vazamentos de gás.

O projeto busca contribuir para a prevenção de acidentes em residências, comércios e indústrias.

🎯 Objetivo

Desenvolver uma solução tecnológica capaz de auxiliar na identificação de possíveis vazamentos de gás, contribuindo para a segurança das pessoas e dos ambientes.

💻 Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- IoT (Internet das Coisas)

⚙️ Funcionalidades

- Apresentação da empresa GasSafe.
- Exibição dos produtos.
- Formulário de contato.
- Consulta de CEP por API.

🎓 Projeto acadêmico

Desenvolvido como parte das atividades do curso de Tecnologia em Análise e Desenvolvimento de Sistemas.
